::rappel{titre="La boîte à outils du chapitre"}
- `struct Point { int x; int y; };` crée un **nouveau type** fait de plusieurs **champs**. On déclare `struct Point p;` et on accède aux champs par un **point** : `p.x`.
- Depuis C99 : `struct Point p = {.x = 3, .y = 4};`.
- Avec un **pointeur** vers une structure, `p->x` est un raccourci de `(*p).x`.
- `typedef struct Point Point;` permet d'écrire `Point` au lieu de `struct Point`.
- Les champs d'une structure sont rangés **dans l'ordre de leur déclaration** ; chaque champ est placé à une adresse **multiple de son alignement**, quitte à insérer des **octets de compensation**.
- Une **union** ne contient **qu'un seul** de ses champs à la fois : tous partagent les mêmes octets, et sa taille est celle du **plus grand**.
- Un **enum** crée un type entier et des **constantes** nommées ; sans valeur précisée, elles valent $0$, $1$, $2$… à la suite de la précédente.
::

## 1. Définir une structure et s'en servir

Une **structure** permet de **créer un nouveau type**, combinaison de plusieurs **champs**. On la définit avec le mot-clé `struct`, suivi de son nom, puis de la déclaration des variables qu'elle contient, entre accolades — et d'un **point-virgule** final :

```c
struct User {
    int age;
    float height;
    char* password;
};
```

On déclare ensuite des variables de ce type en écrivant `struct NomStructure variable;`, et l'on accède à un champ avec un **point** :

```c
struct User alice;
alice.age = 25;
alice.password = "Bonjour";
printf("%d\n", alice.age);
```

Depuis la norme **C99**, on peut aussi donner les valeurs des champs à la déclaration, en les nommant :

```c
struct User alice = {.age = 25, .password = "Bonjour"};
printf("%d %s\n", alice.age, alice.password);
```

L'intérêt : **regrouper** des variables qui vont ensemble. Au lieu de six entiers `x1, y1, z1, x2, y2, z2` et d'une fonction à six arguments, deux `struct Point` et `calc_dist(p1, p2)`.

::rappel{titre="Une coquille de la diapo" icone="i-lucide-triangle-alert"}
La première diapo affiche `alain.name` avec `printf("%d\n", …)`. `name` est une chaîne : il faut `%s`. Avec `%d`, le programme affiche un nombre sans signification (et `gcc` prévient).
::

::exemple{id="s-ex-structure" titre="Copier une structure" pour="Prédire ce que devient une structure affectée ou passée à une fonction"}
```c
struct Point { int x; int y; };

struct Point p = {.x = 3, .y = 4};
struct Point q = p;
q.x = 10;
```

`q = p` **copie tous les champs** : `q` est une autre structure, avec ses propres octets. Modifier `q.x` ne touche pas `p` : à la fin, `p` vaut $(3, 4)$ et `q` $(10, 4)$.

C'est pareil pour un argument : une fonction qui reçoit une `struct Point` reçoit une **copie** (chapitre 3). Pour modifier l'original, il faut lui passer l'adresse.
::

## 2. Pointeurs, malloc et tableaux de structures

On peut réserver de la mémoire pour une structure avec `malloc`, comme pour n'importe quel type :

```c
struct User* alice = malloc(sizeof(struct User));
(*alice).age = 25;
(*alice).password = "Bonjour";
printf("%d %s\n", (*alice).age, (*alice).password);
```

Les parenthèses de `(*alice).age` sont obligatoires — le point passe avant l'étoile. Pour éviter de les écrire à chaque fois, on utilise l'**opérateur flèche** : **`p->champ` équivaut à `(*p).champ`**.

```c
struct User* alice = malloc(sizeof(struct User));
alice->age = 25;
alice->password = "Bonjour";
printf("%d %s\n", alice->age, alice->password);
```

(La diapo écrit `struct User alice = malloc(…)`, sans l'étoile : `malloc` renvoie une adresse, la variable doit être un **pointeur**, `struct User* alice`.)

On peut aussi créer des **tableaux de structures**, sur la pile ou sur le tas :

```c
struct User utilisateurs[5];                                    // 5 utilisateurs, sur la pile
struct User* administrateurs = malloc(2 * sizeof(struct User)); // 2 admins, sur le tas
utilisateurs[0].age = 30;
administrateurs[1].age = 41;
```

::exemple{id="s-ex-fleche" titre="Une fonction qui modifie une structure" pour="Choisir entre le point et la flèche"}
```c
void vieillir(struct User* u) {
    u->age++;
}

int main() {
    struct User ann = {.age = 28};
    vieillir(&ann);
    printf("%d\n", ann.age);   // 29
}
```

Dans `main`, `ann` **est** une structure : on écrit `ann.age`. Dans `vieillir`, `u` est un **pointeur** : on écrit `u->age`. La règle : **point pour une structure, flèche pour un pointeur vers une structure**.

Avec `void vieillir(struct User u) { u.age++; }`, la fonction vieillirait une **copie**, et `main` afficherait $28$.
::

:::qcm{titre="Contrôle express — la flèche" icone="i-lucide-circle-check-big" compact}

## 3. Alias de type : typedef

Pour ne pas écrire `struct` à chaque utilisation, le mot-clé **`typedef`** crée un **alias de type** : un second nom pour un type existant.

```c
typedef struct User User;   // désormais, User veut dire struct User

User ann = {.age = 28, .name = "ann"};
```

On peut aussi définir la structure et son alias d'un coup :

```c
typedef struct Point {
    int x;
    int y;
} Point;
```

::exemple{id="s-ex-typedef" titre="Lire un typedef" pour="Retrouver le type réel derrière un alias"}
`typedef struct Etudiant Etudiant;` se lit : « le nom `Etudiant` désigne le type `struct Etudiant` ». Après lui, `Etudiant e;`, `Etudiant* p;` et `Etudiant t[30];` sont permis. `typedef` ne crée **aucune variable** et ne réserve aucune mémoire : il ne fait que nommer.
::

:::qcm{titre="Contrôle express — typedef" icone="i-lucide-circle-check-big" compact}

## 4. Structure et mémoire : l'alignement

Contrairement aux variables d'une fonction, que le compilateur range comme il veut, **les champs d'une structure sont enregistrés dans l'ordre où ils ont été déclarés**. Le premier champ est au début de la structure, et ainsi de suite :

```c
struct vecteur {
    int taille;      // taille apparaît en premier dans la mémoire
    int* elements;   // elements en second
};
```

Cet ordre a des conséquences, à cause de l'**alignement**. À chaque type est associée une **valeur d'alignement**, et pour des raisons matérielles, **une variable d'un type doit être rangée à une adresse multiple de son alignement**. Si l'alignement d'un `int` est $4$, son adresse doit être un multiple de $4$ ; celui d'un `char` est $1$, il se range partout.

Pour respecter à la fois l'ordre des champs et leur alignement, le compilateur peut **ajouter des octets de compensation** (*padding*) entre deux champs.

::exemple{id="s-ex-alignement" titre="Deux structures, le même contenu, deux dispositions" pour="Placer les champs d'une structure octet par octet"}
Comme la diapo, on prend un `int` sur 4 octets d'alignement $4$, et un `char` d'alignement $1$. Les deux structures commencent à `0xff80`, un multiple de 4.

```c
struct IntChar { int a; char b; };
struct IntChar s = {.a = 5, .b = 6};
```

| Champ | Valeur | Adresses |
|---|---|---|
| `a` | 5 | `0xff80` – `0xff83` |
| `b` | 6 | `0xff84` |

```c
struct CharInt { char a; int b; };
struct CharInt s = {.a = 5, .b = 6};
```

| Champ | Valeur | Adresses |
|---|---|---|
| `a` | 5 | `0xff80` |
| compensation | ?? | `0xff81` – `0xff83` |
| `b` | 6 | `0xff84` – `0xff87` |

Dans `CharInt`, `b` ne peut pas commencer à `0xff81` (pas un multiple de 4) : trois octets de compensation sont insérés. **Ranger les champs du plus aligné au moins aligné** évite ce gaspillage.

En plus de la diapo : la taille totale d'une structure est elle aussi arrondie au multiple de son plus grand alignement, pour qu'un **tableau** de structures garde chaque `int` aligné. Sur un PC, `sizeof(struct IntChar)` et `sizeof(struct CharInt)` valent tous deux $8$.
::

:::qcm{titre="Contrôle express — l'alignement" icone="i-lucide-circle-check-big" compact}

## 5. Les unions

Une **union** se déclare comme une structure, mais elle **ne contient qu'un seul de ses champs à la fois**.

```c
struct point {
    int x;    // la structure contient toujours x ET y
    int y;
};

union nombre {
    int entier;     // l'union contient soit un entier,
    float reel;     // soit un float, jamais les deux
};
```

Comme elle ne contient qu'un champ à la fois, **sa taille est celle de son plus grand champ**, et **tous ses champs partagent la même mémoire** : écrire dans l'un **écrase** tous les autres.

```c
union Info {      // une variable de type union Info n'utilise que 4 octets
    float taille;
    char nom[4];
};
```

Exemples d'usage : la réponse d'une base de données, qui est **soit** une liste de résultats **soit** un message d'erreur ; une forme qui est **soit** un triangle, **soit** un rectangle, **soit** un octogone ; un animal qui est **soit** un chat, **soit** un cheval, **soit** un chien.

::exemple{id="s-ex-union" titre="Écrire un champ écrase l'autre" pour="Dessiner une union dans la mémoire"}
```c
union Info information;
strcpy(information.nom, "abc");      // nom occupe les 4 octets
printf("info: %s\n", information.nom);
information.taille = 168.2;           // taille réutilise les mêmes 4 octets
printf("info: %f\n", information.taille);
```

| Après | `0xff150` | `0xff151` | `0xff152` | `0xff153` |
|---|---|---|---|---|
| `strcpy(…, "abc")` | 97 (`a`) | 98 (`b`) | 99 (`c`) | 0 |
| `taille = 168.2` | les 4 octets du `float` 168,2 | | | |

Le premier `printf` affiche `info: abc` ; le second `info: 168.199997` — un `float` n'a que 7 chiffres significatifs. Après la seconde affectation, `information.nom` ne contient plus `"abc"` : ses octets sont ceux du nombre.

La diapo écrit `information.nom = "abc";`, mais **on n'affecte pas un tableau** en C : on copie la chaîne avec `strcpy` (de `string.h`). Elle utilise aussi un champ `age` que `union Info` n'a pas — l'idée reste la même : le dernier champ écrit écrase les autres.
::

## 6. Les enums

Un **enum** (énumération) crée un **nouveau type entier**, avec des **constantes** associées. On le déclare par son nom, puis la liste des constantes séparées par des virgules :

```c
enum couleur {
    ROUGE = 0,
    BLEU = 1,
    VERT = 2,
    BLANC = 3,
};
```

**Si on ne précise pas la valeur** d'une constante, elle est affectée automatiquement : la première vaut $0$, et chacune vaut **la précédente plus 1**.

```c
typedef enum affichage { GAUCHE, DROITE, LIBRE = 200 } affichage;

affichage opt = GAUCHE;
printf("%d\n", opt);      // 0
printf("%d\n", DROITE);   // 1
printf("%d\n", LIBRE);    // 200
```

(La diapo écrit `DROIT` dans le second `printf` : c'est `DROITE`.)

::exemple{id="s-ex-enum" titre="Une valeur sans valeur, après une valeur" pour="Calculer la valeur de chaque constante"}
```c
typedef enum { LUNDI, MARDI, MERCREDI = 10, JEUDI } jour;
```

`LUNDI` vaut $0$, `MARDI` $1$, `MERCREDI` $10$ (précisé), et `JEUDI`, sans valeur, vaut **la précédente plus 1** : $11$ — pas $3$.

Un enum rend le code lisible : `if (j == MERCREDI)` dit ce qu'il teste, `if (j == 10)` non.
::

:::qcm{titre="Contrôle express — les enums" icone="i-lucide-circle-check-big" compact}

::qcm-question{label="1." bonne="b" cours="s-c-enums"}

#indice

#solution

**Les distracteurs :** **c** compte la position dans la liste ; **a** prend la valeur de `MAX` ; **d** ajoute 2.
::

::

`enum nom { A, B, C = 10, D };` : un type entier et des constantes. Sans valeur précisée, une constante vaut **la précédente plus 1** (la première, $0$) : ici `A` = 0, `B` = 1, `C` = 10, `D` = 11.
