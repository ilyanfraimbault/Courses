::rappel{titre="Comment se servir de cette fiche" icone="i-lucide-compass"}
Trois paliers, à prendre dans l'ordre :

1. **La mémoire, case par case** — on écrit ce que contient chaque case une fois le programme terminé, exactement comme les tableaux des diapos. Un caractère s'écrit entre apostrophes (`'C'`) — inutile de connaître son code ASCII, mais il est accepté aussi ; une case jamais écrite se note `??`.
2. **Ce qu'affiche le programme** — on tape la sortie, caractère pour caractère (les espaces ne comptent pas).
3. **Écrire un programme** — sur une feuille ou dans un éditeur, **compile et teste** avant d'ouvrir la solution, puis compare.

Conventions des tableaux : `char` 1 octet, `int` 2 octets, `float` 4 octets, variables rangées dans l'ordre de déclaration.
::

::::exercice{titre="Palier 1 — La mémoire, case par case" theme="Déclarations, affectations, caractères, ++ et --" badge="★☆☆☆☆" icone="i-lucide-memory-stick" entete="introduction"}
Pour chaque programme, la question à se poser à chaque ligne : **cette ligne réserve-t-elle de la place, écrit-elle dans une case, ou les deux ?** Puis on remplit le tableau tel qu'il est **après la dernière ligne**. Fais-le d'abord ligne par ligne sur une feuille : c'est ce qu'on demande en contrôle.

:::exo-question{label="1." cours="b-c-memoire"}
```c
int x = 3;
char c = 'B';
int y;
y = x * 2 + 1;
c = c + 1;
```

::tableau-memoire
---
titre: Après la dernière ligne
cases:
  - variable: x
    adresse: Octet 1
    octets: 2
    attendu: '3'
  - variable: c
    adresse: Octet 3
    attendu: ["'C'", 'C', '67']
  - variable: y
    adresse: Octet 4
    octets: 2
    attendu: '7'
---
::

#indice
`c + 1` est le caractère qui suit `'B'`. La ligne `int y;` réserve deux octets sans rien y écrire ; c'est la ligne suivante qui les remplit.

#solution
| Ligne | Effet |
|---|---|
| `int x = 3;` | réserve les octets 1–2, écrit $3$ |
| `char c = 'B';` | réserve l'octet 3, écrit `'B'` |
| `int y;` | réserve les octets 4–5 : `??` |
| `y = x * 2 + 1;` | écrit $3 \times 2 + 1 = 7$ dans `y` |
| `c = c + 1;` | écrit le caractère suivant, `'C'`, dans `c` |

À la fin : `x` = $\boxed{3}$, `c` = **`'C'`**, `y` = $\boxed{7}$.
:::

:::exo-question{label="2." cours="b-c-ascii"}
```c
char a = 'a';
char b = a + 2;
int n = b - a;
a = a - 'a' + 'A';
```

::tableau-memoire
---
titre: Après la dernière ligne
cases:
  - variable: a
    adresse: Octet 1
    attendu: ["'A'", 'A', '65']
  - variable: b
    adresse: Octet 2
    attendu: ["'c'", 'c', '99']
  - variable: n
    adresse: Octet 3
    octets: 2
    attendu: '2'
---
::

#indice
Pas besoin des codes : les lettres se suivent. `a - 'a'` est la distance de `a` à `'a'` ; ajoutée à `'A'`, elle donne la majuscule.

#solution
- `a` reçoit `'a'` ;
- `b` reçoit la lettre 2 crans après : `'c'` ;
- `n` reçoit `'c' - 'a'`, la distance entre les deux lettres : $2$ — `n` est un `int`, deux octets ;
- `a - 'a'` vaut $0$ (`a` contient encore `'a'`), donc `a` reçoit `'A' + 0` : `'A'`.

À la fin : `a` = **`'A'`**, `b` = **`'c'`**, `n` = $\boxed{2}$.
:::

:::exo-question{label="3." cours="b-c-affectation"}
```c
int i = 4;
int j = i++ * 2;
int k = --i + j;
i += k;
```

::tableau-memoire
---
titre: Après la dernière ligne
cases:
  - variable: i
    adresse: Octet 1
    octets: 2
    attendu: '16'
  - variable: j
    adresse: Octet 3
    octets: 2
    attendu: '8'
  - variable: k
    adresse: Octet 5
    octets: 2
    attendu: '12'
---
::

#indice
`i++` renvoie l'**ancienne** valeur avant d'augmenter `i` ; `--i` diminue `i` **puis** renvoie la nouvelle. Tiens un tableau ligne par ligne.

#solution
| Ligne | `i` | `j` | `k` |
|---|---|---|---|
| `int i = 4;` | 4 | | |
| `int j = i++ * 2;` | 5 | $4 \times 2 = 8$ | |
| `int k = --i + j;` | 4 | 8 | $4 + 8 = 12$ |
| `i += k;` | $4 + 12 = 16$ | 8 | 12 |

À la fin : `i` = $\boxed{16}$, `j` = $\boxed{8}$, `k` = $\boxed{12}$.
:::

:::exo-question{label="4." cours="b-c-memoire"}
```c
int a;
int b = 7;
a = b % 3;
b = b / 2;
char c;
```

::tableau-memoire
---
titre: Après la dernière ligne
cases:
  - variable: a
    adresse: Octet 1
    octets: 2
    attendu: '1'
  - variable: b
    adresse: Octet 3
    octets: 2
    attendu: '3'
  - variable: c
    adresse: Octet 5
    attendu: ['??', '?']
---
::

#indice
Deux pièges : la division entre deux `int`, et une variable déclarée mais jamais écrite.

#solution
- `a` est réservé sans valeur, puis reçoit $7 \% 3 = 1$ ;
- `b` passe de $7$ à $7 / 2 = 3$ : division **entière** ;
- `c` est réservé mais **jamais écrit** : sa case contient `??`.

À la fin : `a` = $\boxed{1}$, `b` = $\boxed{3}$, `c` = $\boxed{??}$.
:::

::::exercice{titre="Palier 2 — Ce qu'affiche le programme" theme="printf et ses formats, division entière, conditions, opérations bit à bit" badge="★★☆☆☆" icone="i-lucide-terminal" entete="introduction"}
Le geste du contrôle : lire un petit programme et écrire **exactement** ce qui apparaît dans le terminal. Avant de taper, demande-toi pour chaque `%` : **quelle valeur, et sous quelle forme** — nombre, caractère, six décimales ?

:::exo-question{label="5." cours="b-c-entiers"}
```c
printf("%d %d\n", 17 / 5, 17 % 5);
```

::champs-reponse
---
champs:
  - libelle: Ligne affichée
    attendu: '3 2'
---
::

#indice
Écris la division euclidienne de $17$ par $5$.

#solution
$17 = 3 \times 5 + 2$ : le quotient entier vaut $3$, le reste $2$. Le programme affiche **`3 2`**.
:::

:::exo-question{label="6." cours="b-c-printf"}
```c
char c = 'a' + 2;
printf("%c%d\n", c, c - 'a');
```

::champs-reponse
---
champs:
  - libelle: Ligne affichée
    attendu: 'c2'
---
::

#indice
`c` contient $99$. Que montre `%c` de ce nombre, et que vaut `c - 'a'` ?

#solution
`c` vaut $97 + 2 = 99$ : `%c` affiche le caractère `c`. Puis `c - 'a'` vaut $99 - 97 = 2$, affiché par `%d`. Les deux formats sont collés dans la chaîne, la sortie aussi : **`c2`**.
:::

:::exo-question{label="7." cours="b-c-conditions"}
```c
int n = 12;
if (n % 3 == 0 && n % 2) {
    printf("A\n");
} else if (n > 10) {
    printf("B\n");
} else {
    printf("C\n");
}
```

::champs-reponse
---
champs:
  - libelle: Ligne affichée
    attendu: 'B'
---
::

#indice
Évalue chaque morceau de la première condition : que vaut `n % 2` pour $12$, et est-ce vrai ou faux ?

#solution
`n % 3 == 0` vaut $1$ (vrai), mais `n % 2` vaut $0$ (**faux**) : le `&&` est faux. On passe au `else if` : $12 > 10$ est vrai. Le programme affiche **`B`**.

`else if` n'est pas un nouvel opérateur : c'est un `else` dont le bloc est un autre `if`.
:::

:::exo-question{label="8." cours="b-c-bits"}
```c
printf("%d %d %d\n", 9 & 5, 9 | 5, 9 ^ 5);
```

::champs-reponse
---
champs:
  - libelle: 9 & 5
    attendu: '1'
  - libelle: 9 | 5
    attendu: '13'
  - libelle: 9 ^ 5
    attendu: '12'
---
::

#indice
$9$ = `1001`, $5$ = `0101`. Pose-les l'un sous l'autre.

#solution
```
9 = 1001
5 = 0101
```

- ET : `0001` = $\boxed{1}$ ;
- OU : `1101` = $\boxed{13}$ ;
- OU exclusif : `1100` = $\boxed{12}$.
:::

:::exo-question{label="9." cours="b-c-entiers"}
```c
float m = (12 + 15) / 2;
printf("%f\n", m);
```

::champs-reponse
---
champs:
  - libelle: Ligne affichée
    attendu: '13.000000'
---
::

#indice
Le calcul `(12 + 15) / 2` se fait **avant** de ranger le résultat dans `m`. Entre quels types ?

#solution
`12 + 15` vaut $27$, un `int` ; `27 / 2` est une division **entière** : $13$. Ce n'est qu'ensuite que $13$ est rangé dans le `float` `m`, qui vaut donc $13{,}0$, et `%f` écrit six décimales : **`13.000000`**.

Pour obtenir $13{,}5$, il faut `(12 + 15) / 2.0`.
:::

::::exercice{titre="Palier 3 — Écrire un programme" theme="Programmes complets avec scanf, printf, if et else" badge="★★★☆☆" icone="i-lucide-code-xml" entete="introduction"}
Chaque question demande un programme complet : `#include <stdio.h>`, `int main() { … }`. Écris-le, **compile-le avec `gcc`** et teste-le sur deux ou trois valeurs — dont une qui piège — avant de comparer à la solution. Une solution différente de la tienne peut être tout aussi juste : ce qui compte, c'est la sortie.

:::exo-question{label="10." cours="b-c-conditions" code="c"}
Écrire un programme qui lit un entier et affiche `pair` ou `impair`.

#indice
Le reste de la division par $2$ dit tout. Et une condition est un entier : $0$ faux, le reste vrai.

#solution
```c
#include <stdio.h>

int main() {
    int n;
    printf("Entre un entier :\n");
    scanf("%d", &n);
    if (n % 2 == 0) {
        printf("pair\n");
    } else {
        printf("impair\n");
    }
}
```

Teste avec $4$, $7$ et $0$ ($0$ est pair). On aurait pu écrire `if (n % 2)` en échangeant les deux branches. Attention, pour un négatif impair, `n % 2` vaut $-1$ : le test `n % 2 == 1` serait faux, d'où le test `== 0`.
:::

:::exo-question{label="11." cours="b-c-ascii" code="c"}
Écrire un programme qui lit une lettre minuscule et affiche la majuscule correspondante. Si le caractère lu n'est pas une minuscule, il affiche `pas une minuscule`.

#indice
Les minuscules vont de `'a'` à `'z'` et se suivent, tout comme les majuscules : décale depuis `'a'` vers `'A'`. Pour lire un caractère : `scanf(" %c", &c);`.

#solution
```c
#include <stdio.h>

int main() {
    char c;
    scanf(" %c", &c);
    if (c >= 'a' && c <= 'z') {
        printf("%c\n", c - 'a' + 'A');
    } else {
        printf("pas une minuscule\n");
    }
}
```

- `c >= 'a' && c <= 'z'` compare des **codes** : de $97$ à $122$ ;
- `c - 'a'` est le rang de la lettre (0 pour `a`) ; ajouté à `'A'`, il donne la majuscule, que `%c` affiche — aucun code à connaître ;
- l'espace devant `%c` saute les espaces et sauts de ligne éventuels avant la lettre.
:::

:::exo-question{label="12." cours="b-c-entiers" code="c"}
Écrire un programme qui lit deux entiers `a` et `b` et affiche `a / b = q reste r`. Si `b` vaut $0$, il affiche `division par zero` au lieu de calculer.

#indice
Lis les deux nombres d'un seul `scanf`. Teste `b` **avant** de diviser : diviser un entier par zéro fait planter le programme.

#solution
```c
#include <stdio.h>

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    if (b == 0) {
        printf("division par zero\n");
    } else {
        printf("%d / %d = %d reste %d\n", a, b, a / b, a % b);
    }
}
```

Avec `35 8`, la sortie est `35 / 8 = 4 reste 3`. `int a, b;` déclare deux `int` d'un coup.
:::

:::exo-question{label="13." cours="b-c-bits" code="c"}
Écrire un programme qui lit deux entiers `n` et `k` et affiche le bit de rang `k` de `n` (le rang $0$ est le bit de poids faible), c'est-à-dire `0` ou `1`.

#indice
Amène le bit voulu tout à droite avec un décalage, puis isole-le avec un ET.

#solution
```c
#include <stdio.h>

int main() {
    int n, k;
    scanf("%d %d", &n, &k);
    printf("%d\n", (n >> k) & 1);
}
```

`n >> k` décale le bit de rang `k` jusqu'au rang $0$ ; `& 1` efface tous les autres. Pour $n = 13$ = `1101` : le rang $2$ donne `1`, le rang $1$ donne `0`.

Les parenthèses ne sont pas là pour faire joli : `>>` passe bien avant `&`, mais les écrire évite de se poser la question.
:::

::extrait-cours{id="b-c-memoire" titre="Une variable dans la mémoire" source="/cours/a1/mise-a-niveau-c/les-bases/cours#_3-les-variables-dans-la-mémoire"}
Une **déclaration réserve** des octets (dans le cours : `char` 1, `int` 2, `float` 4), à la suite des précédents. Une **affectation écrit** dans ces octets, sans rien réserver. Une variable déclarée sans valeur contient ce qui traînait là : `??`.
::

::extrait-cours{id="b-c-ascii" titre="La table ASCII" source="/cours/a1/mise-a-niveau-c/les-bases/cours#_4-les-caractères-et-la-table-ascii"}
Un caractère entre apostrophes est **un nombre** :

Pas besoin de connaître les codes : les chiffres, les minuscules et les majuscules **se suivent**. On calcule en décalant : `'a' + 4` vaut `'e'`, `ch - '0'` convertit un chiffre en entier, `c - 'a' + 'A'` donne la majuscule de `c`.
::

::extrait-cours{id="b-c-affectation" titre="Les opérateurs d'affectation" source="/cours/a1/mise-a-niveau-c/les-bases/cours#_9-les-opérateurs-daffectation"}
Une affectation est une expression qui **renvoie** une valeur :

- `c = b`, `c += b`… renvoient la **nouvelle** valeur de `c` ;
- `c++`, `c--` modifient `c` et renvoient l'**ancienne** ;
- `++c`, `--c` modifient `c` et renvoient la **nouvelle**.
::

::extrait-cours{id="b-c-entiers" titre="Division entière et modulo" source="/cours/a1/mise-a-niveau-c/les-bases/cours#_5-opérations-sur-les-entiers"}
Entre deux entiers, `/` **tronque** et `%` donne le **reste** : $23 = 5 \times 4 + 3$, donc `23 / 4` vaut $5$ et `23 % 4` vaut $3$. Pour une division à virgule, un des opérandes doit être à virgule **avant** la division : `7 / 2.0` vaut $3{,}5$.
::

::extrait-cours{id="b-c-printf" titre="printf et scanf" source="/cours/a1/mise-a-niveau-c/les-bases/cours#_7-afficher-et-lire-printf-et-scanf"}
`printf(format, valeurs…)` : chaque `%` du format est remplacé, dans l'ordre, par une valeur — `%d` un `int`, `%f` un `float` (six décimales), `%c` le **caractère** de ce code ASCII.

`scanf(format, &variable)` : mêmes formats, et **un `&`** devant chaque variable à remplir. `" %c"` saute les blancs avant de lire un caractère.
::

::extrait-cours{id="b-c-conditions" titre="Conditions" source="/cours/a1/mise-a-niveau-c/les-bases/cours#_8-les-conditions-if-et-else"}
`if (condition) { … } else { … }`. Une condition est un entier : **$0$ = faux, tout le reste = vrai**. Comparaisons et logique (`&&`, `||`, `!`) renvoient $1$ ou $0$. `=` affecte, `==` compare.
::

::extrait-cours{id="b-c-bits" titre="Les opérateurs bit à bit" source="/cours/a1/mise-a-niveau-c/les-bases/cours#_6-opérations-bit-à-bit"}
- `&` : 1 si les deux bits valent 1 ; `|` : si au moins un ; `^` : si exactement un ;
- `x << k` multiplie par $2^k$, `x >> k` divise (entièrement) par $2^k$ ;
- `~x` inverse tous les bits.

Pour lire le bit de rang `k` de `n` : `(n >> k) & 1`.
::
