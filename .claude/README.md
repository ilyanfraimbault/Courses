# .claude

Mémoire du projet, versionnée, à l'usage de qui reprend le travail — humain ou
assistant.

- `CLAUDE.md` — le projet, ses invariants, la façon d'y travailler. **À lire en
  premier.**
- `pieges.md` — les pièges rencontrés et ce qui les a démasqués. Presque aucun
  ne lève d'erreur.
- `etat.md` — où en est le projet, ce qui reste, la dette, et les choix déjà
  tranchés.

La documentation destinée à l'usage courant est dans `docs/` : `contenu.md`,
`comptes.md`, `deploiement.md`.
